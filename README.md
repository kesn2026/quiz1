# 🎉 청춘 퀴즈팡 (QuizPang)

> **수업 도중 배운 내용을 쉽고 재미있게 확인하는 성인 맞춤형 실시간 퀴즈 플랫폼**  
> 큰 글씨, 시인성 높은 디자인, PPT/PDF 및 주제어 기반 자동 생성, 스마트폰 QR코드 실시간 참여 & 등수 표기 지원.

---

## 🌟 주요 기능

1. **👴 어른/시니어 친화적 디자인**
   - 32px 이상의 큼직한 고대비 글씨와 쾌적한 줄 간격
   - 직관적인 4색 선택지 기호(▲, ◆, ●, ■) 및 대형 OX 버튼
   - Web Audio API 기반의 청아한 효과음 (정답 딩동댕, 오답 땡, 째깍째깍 타이머, 승리 팡파레)

2. **📚 스마트 퀴즈 생성 엔진**
   - **주제어 검색**: 원하는 키워드(예: `스마트폰`, `건강상식`, `역사`, `속담`, `금융`)를 입력하면 5문항 3세트(총 15문항)가 즉시 자동 생성
   - **PPT/PDF/TXT 파일 업로드**: 강의 자료를 드래그 앤 드롭하면 본문 핵심 내용을 추출하여 퀴즈 및 해설 자동 제작
   - **3페이지 탭 & 새로고침**: 5문제씩 나누어진 1/2/3페이지를 손쉽게 오가며 퀴즈를 선택하고, [새로운 퀴즈 뽑기]로 무제한 셔플 가능
   - **Gemini AI 연동**: Gemini API 키를 넣으면 최신 생성형 AI로 무제한 퀴즈 생성 지원

3. **📱 QR코드 스마트폰 실시간 참여 (Kahoot 스타일)**
   - 대형 스크린/빔프로젝터에 Wi-Fi 접속용 대형 QR 코드 및 4자리 방 번호(PIN) 표시
   - 학습자들은 별도 앱 설치 없이 스마트폰 카메라로 QR 코드를 비추면 즉시 참여
   - 닉네임과 귀여운 캐릭터 아이콘 선택 후 실시간 참여

4. **🏆 실시간 순위표 및 명예의 전당**
   - 문제 풀이 속도와 연속 정답에 따른 보너스 점수 시스템
   - 매 문제 종료 후 정답 해설 및 실시간 순위표 확인
   - 퀴즈 종료 시 1등, 2등, 3등 시상대(Podium)와 축하 폭죽(Confetti) 연출

---

## 🚀 실행 방법

### 방법 1: 원클릭 실행 (가장 간단)
- 폴더 내 **`start.bat`** 파일을 더블 클릭합니다.
- 서버가 실행되면서 웹 브라우저(`http://localhost:3000`)가 자동으로 열립니다.

### 방법 2: 명령줄(CLI) 실행
```bash
agy-node server.js
# 또는
node server.js
```

---

## 📖 사용 가이드

1. **강사(호스트)**:
   - `http://localhost:3000` 접속
   - 주제를 검색하거나 수업 PPT/PDF 파일을 올립니다.
   - [📱 QR코드로 다 함께 풀기] 버튼을 누르면 대형 QR 코드 대기실이 열립니다.
   - 학습자들이 스마트폰으로 접속하면 [▶ 퀴즈 시작하기!] 버튼을 눌러 진행합니다.

2. **학습자(참가자)**:
   - 스마트폰 기본 카메라로 화면의 QR 코드를 비춥니다.
   - 닉네임과 아이콘을 고르고 [입장하기]를 누릅니다.
   - 화면에 문제가 나오면 해당하는 색깔 버튼(또는 O/X)을 탭합니다.
